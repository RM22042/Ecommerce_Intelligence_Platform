# Olist E-Commerce Intelligence Platform

## 1. Project Overview

The Olist E-Commerce Intelligence Platform is an end-to-end data analytics and data engineering project built using the Brazilian Olist E-Commerce Public Dataset.

The project focuses on transforming raw e-commerce data into meaningful business insights through data exploration, data cleaning, SQL analysis, data warehouse development, and interactive Power BI dashboards.

## 2. Project Objectives

- Analyse e-commerce sales and customer behaviour.
- Identify top-performing products and sellers.
- Evaluate delivery performance and order trends.
- Build a structured PostgreSQL data warehouse.
- Develop interactive dashboards for business decision-making.

## 3. Technologies Used

- Python – Data exploration and preprocessing
- Pandas and NumPy – Data manipulation
- PostgreSQL – Data storage and warehousing
- SQL – Data analysis and business queries
- Power BI – Interactive dashboards
- Jupyter Notebook – Exploratory data analysis

## 4. Project Workflow

1. Dataset collection
2. Data exploration and quality checks
3. Data cleaning and preprocessing
4. Data transformation using Python
5. Loading data into PostgreSQL
6. Designing fact and dimension tables
7. Performing business analysis using SQL
8. Connecting PostgreSQL to Power BI
9. Building interactive dashboards

## 5. Dashboard Structure

### Page 1 – Executive Overview
- Total revenue
- Total orders
- Delivered orders
- Average order value
- Monthly revenue trends

### Page 2 – Product & Seller Analysis
- Top 10 best-selling products
- Top 10 sellers by revenue
- Revenue by product category

### Page 3 – Customer & Delivery Performance
- Order status distribution
- Customer state-wise revenue
- Delivery performance
- Delivery delay analysis

## 6. Expected Business Value

The platform helps businesses understand sales performance, customer distribution, product demand, seller contribution, and delivery efficiency to support data-driven decisions.
